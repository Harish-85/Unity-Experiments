## Experiments
 Just a bunch of random stuff i work on in Unity

# This contains the following mini projects
 1. ASCII Shader
    A full screen shader that renders the world using ASCII characters
 2. Interior Parallax Shader
    A Interior parallax shader inspired by the parallax shader in Spiderman
 3. Compute shader mesh alteration + readback
    Apply mesh deformation via a compute shader and then read that value back from the GPU to the CPU to update collision shape
 4. GPU Particle based Fluid Sim
    A simple fluid simulation that runs using Compute Shaders
 5. A Octree implementation
 6. Dependency Injection using Reflection
